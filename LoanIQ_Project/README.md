# LoanIQ – Intelligent Loan Analytics & Risk Intelligence

An academic Streamlit dashboard for loan portfolio analytics using **synthetic demonstration data**.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`
4. Run `python generate_data.py` to create `data/loan_applications_raw.csv`.
5. Run `streamlit run app.py`

If the CSV is absent, the app generates synthetic data in memory.

## Modules
- Executive Command Centre
- Loan Portfolio Analytics
- Credit Risk Intelligence
- Customer Segmentation
- Data Quality & EDA
- What-if Loan Simulator
- Data Export

## Academic scope
The individual project covers synthetic data generation, cleaning/transformation, descriptive analytics, diagnostic analytics, correlation analysis and an interactive dashboard. Model training/classification, clustering algorithms and association-rule mining/regression are listed in the supplied brief as group-project work and are not claimed as completed here.

## Important limitation
All records and outcomes are synthetic. The simulator is illustrative and must not be used for actual lending, underwriting or credit decisions.
